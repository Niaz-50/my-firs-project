# Мой DevOps Конспект

## Пройденные команды Git
* `git init` — инициализация репозитория
* `git add .` — подготовка файлов к коммиту
* `git commit -m "текст"` — фиксация изменений
* `git push -u origin main` — отправка веток на GitHub

## Настройка профиля
* `git config --global user.name`
* `git config --global user.email`
